# AI-Agent-Attack-Chain-Auditor

Built by Pranay Meshram | Cyber Security Intern - Nagpur Police

### What is this?
AI Agents ke attack chain ko audit karne wala tool. Jab AI agent tool-call karta hai toh us chain ko check karta hai ki koi prompt injection ya data leak to nahi ho raha.

### Features
- Prompt Injection Detection
- Tool-Chain Hijacking Check
- Sensitive Data Leakage Audit
- Termux Support (Mobile Forensics)

### How to Run
pip install rich
python3 auditor.py
